# TECHTRAP

**Who controls whom?** TECHTRAP is an educational HTML5 Canvas game about using technology wisely.

## About the game

Navigate a colorful Kerala-inspired street with Malayalam signs, shops, landmarks, and technology-themed obstacles. Jump or slide to avoid hazards. Avoid **50 obstacles** to win; repeated collisions increase the character's size and eventually end the game.

**Controls:** Space / Up Arrow = Jump; Down Arrow = Slide; M = Mute. Touchscreen players use the on-screen Jump and Slide buttons.

The app is standalone: it needs no npm installation, server, database, external scripts, or analytics.
